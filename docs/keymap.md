# 按键设计与设置方法

预设文件：[`preset/keymap.json`](../preset/keymap.json)。映射采用 SayAll 1.9.21 偏好字段；`preset/apply.py` 会将其合并到已配对的 RC003 档案，不复制任何人的完整偏好文件。

## 为什么这样排

- 四个方向始终保持方向含义：短按移动一次、按住连续移动，不分配独立双击或长按动作。
- 返回负责删除，电源短按负责 Esc 取消；删除不会因连续点按变成撤销。
- 菜单短按 Tab 到下一个控件，TV 长按 Shift-Tab 回上一个控件；菜单双击复制、长按粘贴。
- 音量键成对：短按滚动，双击撤销/重做，长按前后导航。独立长按使音量滚动不再按住连发，长页面可以连续短按滚动。
- 主页负责进入工作：单击会话查找/命令菜单、双击 Chrome、长按 Codex。TV 单击仍切应用、双击仍选模型。

## 具体动作

| 键 | 单击 | 双击 | 长按 |
| --- | --- | --- | --- |
| 电源 | `Esc`：取消／关闭弹窗 | 系统媒体播放／暂停 | `⌘W`：关闭标签或窗口 |
| 上 | `↑` | 无 | 保持 `↑`，按住连发 |
| 下 | `↓` | 无 | 保持 `↓`，按住连发 |
| 左 | `←` | 禁用 | 保持 `←`，原生按住连发 |
| 右 | `→` | 禁用 | 保持 `→`，原生按住连发 |
| 确定 | `Return` | `⌘A`：全选 | `⌘Return`：Codex 中尝试切换本次跟进消息的排队／引导方式 |
| 返回 | `Delete` | 禁用 | `⌥Delete`：删词 |
| 主页 | `⌘K`：命令／会话查找 | 打开 Google Chrome | 打开 Codex |
| 菜单 | `Tab`：下一个控件 | `⌘C`：复制 | `⌘V`：粘贴 |
| 音量＋ | 向上滚动 | `⌘Z`：撤销 | `⌃⇧Tab`：上一个最近会话／Chrome 标签 |
| 音量－ | 向下滚动 | `⌘⇧Z`：重做 | `⌃Tab`：下一个最近会话／Chrome 标签 |
| TV | `⌘Tab`：切换应用 | `⌃⇧M`：Codex 模型选择器 | `⇧Tab`：上一个控件 |
| 语音 | 按住说话，松开结束 | 不参与普通映射 | 不参与普通映射 |

`⌘K`、`⌃⇧M` 和 `⌘Return` 是送给当前前台 App 的快捷键；在其他 App 中可能是别的功能或无动作。当前 Codex 桌面版在默认 `composerEnterBehavior = "enter"` 且 `followUpQueueMode = "queue"` 时，只在**正在回复**的本地任务中把 `⌘Return` 作为与排队相反的“引导”；空闲时它正常发送。若回车行为改为 `cmdAlways` 或 `cmdIfMultiline`，对应的相反操作改为 `⌘⇧Return`。**本机实体遥控器已在回复过程中通过引导测试**，其他版本仍应按同样场景验收。普通确定键保留 `Return`，因此仍由 Codex 默认设置决定排队或发送。

SayAll 对双击、长按有识别时间；设置长按的键不会在按住时无限重复。四方向键不设置独立双击或长按动作，保留标准箭头及按住连发；在输入框移动光标，在菜单、列表等支持方向键的控件中移动选项。返回键双击禁用，因此可以连按删除多个字。

## 如何选择会话和控件

- 长按主页打开 Codex；单击主页打开命令菜单。查询会话名，用上下选结果、确定打开，电源短按取消。
- 音量长按使用当前安装版本明确提供的 `previousRecentThread / nextRecentThread` 默认快捷键。它遍历最近访问的会话，不保证按侧边栏项目顺序切换。
- 菜单短按和 TV 长按切换可聚焦控件；是否能进入某个侧边栏区域由目标应用决定。方向键只操作当前焦点，不自动定位鼠标，也不会自动使未聚焦的侧边栏获得焦点。
- 不启用 macOS 完整键盘控制，以免再次干扰浏览器视频空格暂停。
- 其他 App 可能把 `Ctrl+Tab` 或 `⌘K` 解释为别的功能。使用前需在 Codex 与 Chrome 分别实测音量长按；不能仅凭配置保存声称会话/标签切换成功。

## 手动设置

若不使用脚本，可在 SayAll 的“按键”页选中已连接的 RC003，开启自定义按键功能，逐项按上表配置。四方向长按在配置界面设为“禁用/未设置”，这是关闭额外长按动作、保留原生按住连发；不要把长按另设为“方向左/右”，否则只触发一次。`自定义快捷键` 在 GUI 中选择或录入组合键；“主页双击”选“打开自定义 APP”并指定 Chrome。不要设置“聚焦输入框”作为 TV 长按。完成后关闭 SayAll 设置窗口，使目标 App 保持前台，再按实体遥控器测试。

## 自动应用与回滚

从仓库根目录运行 `python3 preset/apply.py` 可只读显示目标档案索引及是否需要变更。完全退出 SayAll 后运行 `python3 preset/apply.py --apply`。脚本会在用户 Library 中备份完整旧偏好并验证写入结果；它不上传备份。若有多个 RC003 档案，显式给 `--profile-index`。

回滚时先退出 SayAll，执行 `defaults import com.hd838a.RemoteMic '<本机备份路径>'`，再启动 SayAll。恢复的是该 Mac 的完整旧偏好，不能拿别人的备份导入。
